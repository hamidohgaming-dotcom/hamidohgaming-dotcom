## 🚀 Quick Start

### 1. View the Showcase Locally
Simply open `index.html` in any modern web browser, or run a local server:

```powershell
# Using Python (if installed)
python -m http.server 3000

# Or using Node.js / npx
npx serve .
```

### 2. Deploy to GitHub (`hamidohgaming-dotcom`)

1. Initialize Git and commit your files:
   ```powershell
   git init
   git add .
   git commit -m "feat: initial release of hamidoh gaming showcase"
   ```

2. Push to your GitHub repository:
   ```powershell
   git branch -M main
   git remote add origin https://github.com/hamidohgaming-dotcom/hamidohgaming-dotcom.git
   git push -u origin main
   ```

3. Enable **GitHub Pages**:
   - Go to your repository settings on GitHub (`Settings` > `Pages`).
   - Under **Build and deployment**, select **GitHub Actions** (the included `.github/workflows/pages.yml` will handle the rest).
